Things that are easy to miss

  • Numbers can be dragged. Put the caret on one and a grip appears under it. Hold Alt for tenths, Shift for tens.
  • Colours open a picker. Any hex, rgb() or hsl() value, in a stylesheet or an inline style.
  • Inspect only points: click an element and the editor jumps to its markup — or, when a stylesheet is the file in front of you, to the rule that styles it; click again for the next rule. Move the caret through your HTML and the element it is in lights up, or through a CSS rule and every element it matches does.
  • Design makes the preview editable: click to select and jump to the markup, drag to move an element, pull the handles to resize it, Delete to remove it. Every gesture edits the source, and Ctrl+Z takes it back.
  • Class names cross over. CSS suggests classes your HTML uses; HTML suggests classes your CSS styles.
  • Open a folder and every HTML, CSS and JavaScript file in it — subfolders included — is loaded and listed under Files. Tabs show the ones you have actually opened; closing a tab does not unload the file.
  • The preview follows one page. Pick it in the dropdown above the preview, click the dot beside an HTML file in the tree, or simply click a link to it in the page; the arrow beside the dropdown, or Alt+← in the page, goes back. Its stylesheets and scripts are resolved the way a browser would resolve them, relative to where that page sits. Links off the site open in a browser tab.
  • Save writes back to the files you opened, in place.
  • Themes are under Theme at the top: light, medium and dark, each with a sample in its own colours. The one you pick is highlighted, and remembered. Each is a short block of colours in themes.css, if you want to make your own.
